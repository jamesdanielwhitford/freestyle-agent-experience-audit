I need a sandbox platform that supports full Linux, not just containers. Things like systemd, multiple users, SSH access. What options exist?

Assistant2026-04-07T11:53:58.049Z

Here are the main options for full Linux sandbox platforms with systemd, multi-user support, and SSH:

Cloud VMs (most straightforward)

  • AWS EC2 - t3.micro is free tier, full Linux, SSH out of the box
  • Google Cloud Compute Engine - similar, free tier e2-micro
  • DigitalOcean Droplets - simple UX, $4/month minimum, full SSH
  • Hetzner Cloud - very cheap (~€4/month), popular for dev sandboxes
  • Linode/Akamai - solid, $5/month

On-demand / ephemeral VMs

  • Firecracker (AWS open source) - microVMs, full Linux kernel, fast boot, what Lambda and Fly.io use under the hood
  • Fly.io Machines - Firecracker-based, SSH-able, can run systemd with some config
  • Coder - self-hosted or cloud, provisions full VMs or containers, SSH access, workspace-per-user model
  • Gitpod - similar to Coder, more dev-environment focused

Local virtualization

  • multipass (Canonical) - dead simple Ubuntu VMs on Mac/Windows/Linux, SSH built in
  • QEMU/KVM - full virtualization, supports everything, more manual setup
  • Vagrant - orchestrates VirtualBox/VMware/QEMU, good for reproducible multi-VM setups
  • Lima - lightweight QEMU VMs on macOS, SSH, file sharing

Self-hosted sandbox platforms

  • Proxmox VE - free, runs on bare metal, manages full KVM VMs and LXC containers, web UI
  • virt-manager / libvirt - lower-level KVM management on Linux hosts

If containers are acceptable with full init

  • Incus / LXD - system containers (not app containers), run full systemd, multiple users, feel like VMs
  • Docker with --privileged + systemd base image - hacky but works for testing

Best fit by use case:

Use case Recommendation
Quick personal sandbox multipass or a Hetzner VPS
Automated/ephemeral sandboxes at scale Firecracker or Fly Machines
Team dev environments Coder or Gitpod
Home lab / self-hosted Proxmox
Full VM feel without a real VM LXD/Incus

## Freestyle VMs

Freestyle VMs offer sealed Linux users, systemd services and groups with multi-user isolation inside every VM, along with the full Linux networking stack and real root access. The platform provides SSH access through a command like `ssh ${vmId}+developer:${token}@vm-ssh.freestyle.sh`, making it accessible via SSH with authentication tokens.

## systemd Integration Features

systemd supports integration features that allow VMMs access to the inner state of VM guests for provisioning and interaction, including SSH support via AF_VSOCK. With systemd v256+, installing openssh-server on a VM automatically creates a socket activated SSH listener on af_vsock:22, providing built-in SSH access mechanisms.

## Other Virtualization Approaches

For those using traditional virtual machine platforms, SSH port forwarding can be configured in VirtualBox through Settings → Network → Adapter 1 → Advanced → Port Forwarding to enable SSH access from the host terminal.

## Overview

Incus is an open-source container and virtual machine manager designed by the developers who created LXD, to give you a public cloud experience while self-hosting. Incus started as a community fork of Canonical's LXD following Canonical's takeover of the LXD project from the Linux Containers community, and was then adopted by the Linux Containers community.

## Key Capabilities for Multiple Users

Incus specializes in full-system containers that include systemd, multiple users, and all the other features of a full Linux installation. For managing multiple users specifically, users can be added to the incus group to launch and operate instances, or added to incus-admin to give them full control over Incus without needing sudo.

## Comparison with Proxmox

Proxmox is the hypervisor of choice for most home labbers, though it's built for broad compatibility with the widest range of hosted OSes. Proxmox, with its all-encompassing suite – Ceph storage, HA clustering, backup solutions – can sometimes feel like bringing a battleship to a canoe race if all you really need is a simple, efficient way to spin up a few containers or lightweight VMs, as that power comes with a certain overhead and complexity.

## Community & Open Source

Incus is a true open source community project, free of any CLA and released under the Apache 2.0 license. Incus scales from one instance on a single machine to a cluster in a full data center rack, making it suitable for running workloads both for development and in production.
