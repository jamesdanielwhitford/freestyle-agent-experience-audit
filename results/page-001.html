Here are 10 lesser-known or newer cloud code sandbox platforms worth knowing about, focused on the 2022-2026 window:

---

**1. E2B (e2b.dev)**
Founded around 2023, E2B is purpose-built for AI agents executing untrusted code. It uses Firecracker microVMs (the same hypervisor technology behind AWS Lambda internals) giving genuine kernel-level isolation with roughly 150ms cold starts. Its main differentiator is developer ergonomics: polished Python and JavaScript SDKs that treat the sandbox as a programmable object, with a fine-grained filesystem API and open-source core. It went from 40,000 sandbox sessions/month in early 2024 to around 15 million/month by early 2025, which signals genuine traction in the LLM tooling space. Pricing: free hobby tier with $100 credit, Pro at $150/month with 24-hour session limits and 20 concurrent sandboxes. Hosted rate roughly $0.000028/CPU/second.

---

**2. Daytona**
Originally a dev environment product, Daytona pivoted hard to AI agent infrastructure in early 2025 after the coding agent wave hit. Its headline claim is sub-90ms sandbox creation latency, faster than any microVM-based competitor. It includes built-in Git and LSP support and a Python SDK with live stdout/stderr streaming, aimed at eval pipelines and coding agents. Isolation is Docker-based by default (weaker than microVMs but faster). Raised a $24M Series A in February 2026. Pricing: $0.067/hr for 1 vCPU / 1 GiB, $200 in free credits to start, with a startup program offering up to $50k in credits.

---

**3. Morph Cloud (morph.so)**
Morph Cloud's distinctive concept is "infinibranch" sandboxes: you can snapshot a running environment mid-execution and branch from it instantly, similar to how git branches from a commit. This is especially useful for AI agents that need to explore multiple execution paths in parallel without re-running setup steps. Supports burst scalability for concurrent agent workloads. The architecture gives each sandbox its own isolated filesystem, network stack, and process tree. Relatively new entrant (2024-2025), positioning is explicitly for AI coding agents, code review bots, and automated testing pipelines.

---

**4. Modal (modal.com)**
Modal is Python-first serverless compute that has evolved into a legitimate sandbox platform for AI workflows. You define a container image in Python code and launch functions inside it with sub-second cold starts. The platform scales to 10,000+ concurrent containers. Unlike most sandbox-specific platforms, Modal has strong GPU support (H100s, A100s), making it useful for ML inference + code execution in one platform. gVisor isolation. Pricing: $0.0000131/CPU/second, with $30/month in free credits on the Starter plan. Team plan is $250/month with $100 credit and 50 GPU concurrency slots.

---

**5. Cloudflare Dynamic Workers**
Launched into open beta in April 2026, Dynamic Workers allow a Cloudflare Worker to instantiate another Worker at runtime with code specified on the fly, each in its own isolate. Uses V8 isolates rather than microVMs, which means startup in a few milliseconds (roughly 100x faster than containers) but a narrower security surface than hypervisor isolation. Cloudflare patches V8 vulnerabilities to production within hours as mitigation. Execution is constrained to JavaScript/TypeScript but runs across Cloudflare's global edge network. Pricing: $0.002 per unique Worker loaded per day (waived during beta), plus standard Workers CPU and invocation charges. No limits on concurrent sandboxes.

---

**6. Together AI Code Sandbox**
Together AI, primarily known as a GPU inference provider, added a Code Sandbox product that integrates VM-based execution directly with their LLM API. The distinguishing angle is co-location: your agent calls an LLM and executes code on the same platform, reducing latency and simplifying billing. Supports Dev Containers for configuring custom setups including databases and servers. VM snapshot/resume in ~500ms. Pricing: VM credits at $0.01486/credit (credits denominate vCPU-hours), Code Interpreter sessions at $0.03/60-minute session.

---

**7. Blaxel (blaxel.ai)**
Came out of Y Combinator's Spring 2025 batch. Blaxel's core thesis is that standby latency matters as much as cold-start latency for agent workloads: sandboxes sit on standby indefinitely and resume in under 25ms. The architecture uses a read-only base filesystem (EROFS) with in-memory writable layers (tmpfs via OverlayFS), preserving the full memory state of running processes. Also includes built-in MCP server integration and REST APIs for filesystem and process management, designed to work with tool-calling agents directly. Scales to zero when idle. Pricing is memory-and-storage based rather than per-CPU-second.

---

**8. Vercel Sandboxes (Beta)**
Vercel launched a beta sandbox product using Firecracker microVMs, tightly integrated into the Vercel deployment ecosystem. Notably, you only pay for active CPU time, not wall-clock time, which can be significantly cheaper for bursty agent workloads. Currently limited to Node.js and Python, single US East region, and session durations of 45 minutes to 5 hours. Pricing: Hobby tier includes 5 free CPU-hours/month, Pro at $0.128/CPU-hour. Beta status means constraints, but the Vercel distribution channel is large.

---

**9. Northflank**
Northflank is a broader developer platform (containers, jobs, databases) that added purpose-built sandbox infrastructure. Its differentiator is bring-your-own-cloud (BYOC): you can run sandboxes inside your own AWS, GCP, or Azure account under your VPC, which matters for compliance-heavy use cases. Supports Kata Containers and gVisor microVM isolation, configurable persistence, and sandboxes that can run indefinitely (no 24-hour caps). Pricing: $0.01667/vCPU-hr, $0.00833/GB-hr, with H100 GPU at $2.74/hr all-inclusive. Reports processing 2M+ isolated workloads monthly.

---

**10. Lifo (lifo.sh)**
The most unusual entry: Lifo is a JavaScript library that provides a Linux-like OS environment running entirely inside the browser, with no cloud infrastructure at all. It maps familiar Unix interfaces to browser APIs: a virtual filesystem backed by IndexedDB, a Bash-like shell with pipes and redirects, 58+ built-in Unix commands, and Node.js compatibility shims. Boot time is ~0ms since there is no VM to start. The use case is AI agents that need sandboxed code execution embedded in a web app without incurring server costs per execution. Pricing: MIT-licensed, completely free, $0 infrastructure cost.

---

**Honorable Mention: Beam Cloud (beam.cloud)**
Beam pitches itself as AI infrastructure for developers with sandbox support for untrusted code at scale, including custom Docker images and GPU support. Open-source core (beta9 on GitHub). Aimed at inference pipelines and background jobs as well as sandboxing.

Here's a rundown of less well-known or newer cloud code sandbox platforms:

4. Modal (modal.com) Python-first serverless compute with strong GPU support (H100s, A100s). Sub-second cold starts, scales to 10K+ concurrent containers. Good for ML inference and code execution combined. $30/month free credits on Starter.

6. Together AI Code Sandbox GPU inference provider that added VM-based code execution co-located with their LLM API. Reduces latency by running model calls and code execution on the same platform. Snapshot/resume in ~500ms.

Honorable mention: Beam Cloud (beam.cloud) Open-source core (beta9 on GitHub), custom Docker images, GPU support, aimed at inference pipelines and background jobs alongside sandboxing.
