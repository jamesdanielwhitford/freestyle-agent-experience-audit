## Dedicated AI Agent VM/Sandbox Platforms with MCP

**E2B**
The most prominent purpose-built option. Runs isolated microVMs via Firecracker (the same tech under AWS Lambda). Has an official MCP server, direct access to Docker's MCP Catalog (200+ tools), and is used by roughly half of Fortune 500 companies for agent workloads. Open-source core (Apache-2.0), with a commercial cloud offering.
- [e2b.dev](https://e2b.dev/) | [GitHub](https://github.com/e2b-dev)

**Daytona**
Pivoted to AI agent infrastructure in early 2025. Provides sub-90ms (sometimes 27ms) sandbox provisioning, supports full Linux/Windows/macOS virtual desktops for computer-use agents, and has an official MCP server implementation for executing AI-generated code. Raised a $24M Series A in February 2026.
- [Daytona blog comparison](https://blaxel.ai/blog/daytona-dev-environment-pricing-alternatives)

**Blaxel**
YC Spring 2025. Runs agents in micro-VMs that resume in under 25ms, co-locates agent APIs with sandboxes, and positions itself explicitly for agentic workloads.
- [Northflank on Blaxel alternatives](https://northflank.com/blog/top-blaxel-alternatives-for-ai-sandbox-and-agent-infrastructure)

**agent-infra/sandbox** (open source)
An all-in-one sandbox combining Browser, Shell, File, MCP, and VSCode Server in a single Docker container, with MCP-compatible APIs for agent integration.
- [GitHub](https://github.com/agent-infra/sandbox)

## Container/MicroVM Runtimes with MCP Support

**Docker Desktop + Docker Sandboxes**
Docker Desktop 4.58 (January 2026) gives each agent a microVM via the native hypervisor with its own private Docker daemon. Docker's MCP Catalog lists 200+ servers. Partnered directly with E2B.
- [Docker + E2B announcement](https://www.docker.com/blog/docker-e2b-building-the-future-of-trusted-ai/)

**Lima v2.0** (open source)
Added GPU acceleration and an MCP server that lets AI agents safely operate inside Linux VMs on macOS.

## Major Cloud Platforms with Managed MCP + VM Execution

**AWS Bedrock AgentCore**
Released October 2025. Managed MCP server deployment on AWS infrastructure, with IAM-secured API access. AWS also ships official MCP servers for EC2, MSK, and other services.
- [AgentCore MCP deployment guide](https://vogla.com/agentcore-mcp-server-deployment-aws-mcp/) | [AWS MCP servers GitHub](https://github.com/awslabs/mcp)

**Google Cloud Managed MCP**
Launched December 2025. Fully managed MCP servers for Google services including BigQuery, Cloud SQL, Spanner, AlloyDB, and Google Maps. Cloud Run and Agent Engine can host agent workloads.
- [Google Cloud MCP announcement](https://cloud.google.com/blog/products/ai-machine-learning/announcing-official-mcp-support-for-google-services)

**Azure Functions MCP Support**
Released January 2026. MCP extension for Azure Functions (.NET, Java, JS, Python, TypeScript) with OBO authentication and streamable HTTP transport. Includes a self-hosted option.
- [InfoQ: Azure Functions MCP](https://www.infoq.com/news/2026/01/azure-functions-mcp-support/)

**Microsoft Azure Foundry MCP Server**
Previewed December 2025. Cloud-hosted MCP server specifically for AI agent development workflows.

## MCP Gateway/Orchestration Layer (sits in front of VM-hosted MCP servers)

**Obot MCP Gateway**
Provides enterprise access control, cataloging, and governance over which MCP servers are exposed to agents. Works with VS Code, GitHub Copilot, and MCP-registry-enabled platforms.
- [obot.ai](https://obot.ai/)
