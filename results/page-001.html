## Research Findings: Freestyle Account Creation & Authentication Options

Based on my research of Freestyle's documentation, GitHub repositories, npm packages, and API endpoints, here's what is and isn't possible programmatically:

---

### **ACCOUNT CREATION & SIGNUP**

**NOT POSSIBLE PROGRAMMATICALLY**
- Freestyle requires account creation through the **web UI only** at [dash.freestyle.sh](https://dash.freestyle.sh)
- There is **no account creation API endpoint** exposed
- No CLI tool exists for initial account signup
- The MCP server does not support account creation

---

### **API KEY GENERATION & RETRIEVAL**

**PARTIALLY POSSIBLE**
- **Initial API Key**: Must be generated through the web dashboard at https://dash.freestyle.sh - no programmatic way to generate this initial key
- **Identity-based Access Tokens**: **ARE** fully programmable via the SDK

Once you have your initial API key, you can generate additional access credentials programmatically:

```javascript
const { identity } = await freestyle.identities.create();
await identity.permissions.git.grant({
  permission: "write",
  repoId: repo.id,
});
const { token } = await identity.tokens.create();
```

---

### **OAUTH FLOWS & TOKEN EXCHANGE MECHANISMS**

**NOT STANDARD OAUTH**
- Freestyle does **not use OAuth 2.0** for standard account flows
- Instead, it uses a **custom identity and token system**:
  - Create identities with `freestyle.identities.create()`
  - Grant granular permissions per resource (Git repos, VMs)
  - Generate access tokens with `identity.tokens.create()`
  - Use tokens via `X-Freestyle-Identity-Access-Token` header or embedded in git clone URLs: `https://x-access-token:<token>@git.freestyle.sh/<repo-id>`

---

### **CLI TOOLS AVAILABLE**

**NO DEDICATED CLI TOOL**
- There is **no CLI tool like `freestyle-cli`** on npm
- The `freestyle-sandboxes` npm package is an **SDK, not a CLI**
- Freestyle integrates with editors via **MCP server** (Claude Code, VSCode, Cursor):
  - Command: `claude mcp add --transport http freestyle-docs https://docs.freestyle.sh/api/mcp/mcp`
  - The MCP server is **read-only documentation**, not for account/auth operations

---

### **MCP SERVER CAPABILITIES**

**What the MCP server DOES**
- Provides access to Freestyle documentation
- Integrates Freestyle docs into editor contexts

**What the MCP server DOES NOT DO**
- Account creation
- API key generation
- Authentication flows
- Programmatic resource management (use SDK instead)

1. Manual: Create account at https://dash.freestyle.sh
