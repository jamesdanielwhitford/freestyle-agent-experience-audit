## Freestyle SDK API for Running Commands in VMs

Based on my research, here are the exact API calls and code needed to execute shell commands and capture output:

### TypeScript/Node.js

**Installation:**
```bash
npm i freestyle-sandboxes
```

**Complete Example - Create VM and Execute Command:**
```typescript
import { freestyle } from "freestyle-sandboxes";

// Set your API key via environment variable
// export FREESTYLE_API_KEY="your-api-key"

async function runCommand() {
  // Create a VM
  const { vm } = await freestyle.vms.create();
  
  // Execute shell command and capture output
  const result = await vm.exec("echo hello world");
  
  console.log("stdout:", result.stdout);
  console.log("stderr:", result.stderr);
  console.log("exit code:", result.statusCode);
}

runCommand();
```

**Response Object Structure:**
```typescript
type ExecResponse = {
  stdout: string;        // The command output
  stderr: string;        // Error output (if any)
  statusCode: number;    // Exit code
};
```

### Python

**Installation:**
```bash
pip install freestyle
```

**Complete Example - Create VM and Execute Command:**
```python
from freestyle import Freestyle

# Set API key via environment variable
# export FREESTYLE_API_KEY="your-api-key"

async def run_command():
    client = Freestyle()
    
    # Create a VM
    vm = await client.vms.create()
    
    # Execute shell command and capture output
    result = await vm.exec("echo hello world")
    
    print(f"stdout: {result['stdout']}")
    print(f"stderr: {result['stderr']}")
    print(f"exit code: {result['statusCode']}")

# Run with asyncio
import asyncio
asyncio.run(run_command())
```

### Advanced TypeScript Example with Multiple Commands

```typescript
import { freestyle, VmSpec } from "freestyle-sandboxes";

async function advancedExample() {
  // Create VM with custom configuration
  const { vm, vmId } = await freestyle.vms.create(
    new VmSpec()
      .withWorkdir("/tmp")
  );

  // Execute multiple commands
  const result1 = await vm.exec("echo hello world");
  console.log("Output:", result1.stdout);
  
  const result2 = await vm.exec("ls -la");
  console.log("Directory listing:", result2.stdout);
  
  // Chain commands with shell
  const result3 = await vm.exec("cd /tmp && pwd && echo 'done'");
  console.log("Chained output:", result3.stdout);
}

advancedExample();
```

### Key API Methods Summary

| Method | Purpose | Returns |
|--------|---------|---------|
| `freestyle.vms.create()` | Creates a new VM sandbox | `{ vm, vmId, domains }` |
| `vm.exec(command)` | Executes a shell command in the VM | `{ stdout, stderr, statusCode }` |
| `vm.node.runCode(code)` | Executes JavaScript (with auto JSON parsing) | `{ result, stdout, stderr, statusCode }` |
| `vm.python.runCode(code)` | Executes Python code | `{ result, stdout, stderr, statusCode }` |

Both SDKs automatically detect the API key from the `FREESTYLE_API_KEY` environment variable:

```bash
export FREESTYLE_API_KEY="your-api-key"
```
